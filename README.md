# Quiz – Lineare Listen

Kleines Multiple-Choice-Quiz für Q1.4.1 Lineare Listen.

## GitHub Pages
1. Dateien in ein GitHub-Repository hochladen.
2. In GitHub: Settings → Pages.
3. Unter „Build and deployment“: Deploy from a branch.
4. Branch `main`, Ordner `/ (root)` auswählen und speichern.
5. Den anschließend angezeigten GitHub-Pages-Link an die Schülerinnen und Schüler verteilen.

Das Quiz läuft vollständig im Browser und benötigt keinen Server.
